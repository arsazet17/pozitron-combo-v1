ПОЗИТРОН КОМБО v1

Файлы для GitHub Pages:
- index.html
- manifest.webmanifest
- sw.js
- assets/icon-192.png
- assets/icon-512.png

Возможности:
- база тиражей в IndexedDB, рассчитана на десятки тысяч записей;
- импорт CSV/JSON;
- обновление с настраиваемого источника;
- K5 и K6 на отслеживании;
- создание вручную, по текущему и историческому тиражу;
- цепочка совпадений по следующим тиражам;
- определение преобладающего рисунка: горизонтальный, вертикальный, диагональный;
- поиск похожих пяти-тиражных участков и предложения комбинаций;
- экспорт полной базы и отслеживаемых комбинаций.

Важно: алгоритм ищет статистическое сходство, а не гарантирует выигрыш.
