# XRAY STRUCTURE 4.1 — независимые COMBO

Исправление только логики четырёх COMBO и cache/version.

- COMBO-5A: самостоятельная ASC-сборка.
- COMBO-5B: самостоятельная Vortex-альтернатива, без чисел 5A.
- COMBO-7A: самостоятельная ROOT/LEVEL-сборка, не строится как 5A + 2; максимум 2 пересечения с 5A.
- COMBO-7B: самостоятельная DRAW/Vortex-ветка; максимум 2 пересечения с 7A.
- Все четыре COMBO выбираются только из frozen прогнозных 20.
- predicted20 и остальная структура Рентгена не менялись.
- XRAY runtime version: XRAY-STRUCTURE-4.1.
- App version: 4.3.4.
- Пакет не содержит data/xray-runtime.json, чтобы не затереть текущий LIVE runtime в репозитории.
