# ПОЗИТРОН КОМБО v1.0.1

Готовый репозиторий приложения с автоматическим обновлением тиражей КЕНО.

- Приложение: `index.html`
- База браузера и комбинации K5/K6 сохраняются в IndexedDB
- Серверная история: `combo-history-v1.json`
- Обновляющий скрипт: `combo-update-v1.js`
- Workflow: `.github/workflows/update-combo-v1.yaml`
- Ручной запуск и автоматический запуск каждые 5 минут

Файл `update-combo-v1.yaml` в корне — видимая мобильная копия workflow. После загрузки его нужно поместить в `.github/workflows`; код файла менять не требуется.
