# COMBO: восстановление автоматического обновления, 15.09.2026

## Подтверждённая причина

В запуске [34976283993](https://github.com/arsazet17/pozitron-combo-v1/actions/runs/34976283993/job/104405240761)
официальный источник успешно проверил 26 записей и получил 25 новых тиражей:
локальный №327575 → №327600. XRAY и журнал также были построены.
Однако `self-test-workflows.mjs` завершился с `SyntaxError: Unexpected token 'a', "name: Apply"... is not valid JSON`.
Он ожидает JSON (допустимое подмножество YAML), а новый `apply-intervals-nav-v1.yml`
был обычным YAML. Общая проверка прервала публикацию до коммита.
Поэтому сайт продолжал получать старый архив, несмотря на успешное чтение Столото.
Ошибка воспроизведена локально на исходном коммите `a856e047`.

Дополнительно обнаружены независимые препятствия автоматическому восстановлению:

- В `update-combo-v1.yaml` отсутствовал `schedule`, оставался только `workflow_dispatch`.
- `fetchJSONLive` не ограничивал ожидание ответа и тела: при зависшем запросе
  `autoRefreshBusy` оставался установленным, блокируя следующие вызовы.
- После ошибки первой загрузки `load()` возвращался до запуска автообновления без повторной попытки.

## Исправление

- Уже выполненный установщик кнопки «Интервалы» сохранён в JSON-формате как
  ручной read-only workflow; его скрипт и установленная кнопка сохранены.
  Он больше не является отдельным писателем main в обход общего publisher.
- Обновление данных запускается каждые 10 минут, в минуты 6/16/26/36/46/56 UTC.
  Общий publisher, проверка Столото 2/3, догоняющая загрузка и проверки целостности сохранены.
  GitHub может задерживать scheduled jobs; следующая попытка получает накопившийся диапазон.
- Запрос JSON вместе с чтением тела ограничен 30 секундами через AbortController.
  Флаг занятости освобождается в `finally`; следующая попытка выполняется автоматически.
  Проверка версии использует тот же сетевой помощник.
- Первая загрузка при сбое повторяется через 10 секунд.
- Обновлены версия приложения, build ID, URL ресурсов, manifest и service worker.
  Живые JSON по-прежнему идут через сеть с `no-store`.

## Согласованные критерии и локальная проверка

Минимум 3 последовательных автоматических обновления без пропусков/дублей;
восстановление после временной ошибки; новая версия после перезагрузки без старого кэша.

`node .github/scripts/check-stage1.mjs` — PASS:

- 19 проверок XRAY: неизменность математического результата, frozen-прогнозов,
  истории и выплат, защита от удаления/сокращения данных.
- 11 проверок UI/PWA: согласованный build, установка/активация SW, сетевые живые данные,
  переход на новую версию и защита от циклических перезагрузок.
- Проверки workflow, повторной публикации при изменении main и базового runtime.
- Новый `self-test-combo-auto-refresh.mjs` выполняет реальные функции из `index.html`
  с управляемым сетевым ответом и таймером на копии четырёх существующих тиражей:
  №327572 → №327573 → №327574 → №327575. Все три автоматических цикла прошли,

Эти три цикла — воспроизводимый тест с сетевыми фикстурами, а не три новых реальных
тиража Столото. Результаты серверной проверки после публикации фиксируются отдельно.
