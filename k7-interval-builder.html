Правильная логика интервалов
Строгий режим
Считает только соседние появления числа: 1→2, 2→3, 3→4. Интервал 0 — число вышло в двух соседних тиражах.
Мягкий режим
Считает все пары появлений: кроме соседних добавляет 1→3, 1→4, 2→4 и т.д. Это не «±1», а плотная картина общего ритма числа.
Фильтр частоты
Интервальный сигнал усиливается, если число само по себе достаточно часто встречалось в выбранном архивном окне.
Это отдельная лабораторная страница. В основное приложение COMBO ничего не встроено и его файлы интерфейса не меняются.
Формирование K7
Расчёт делается только по известным тиражам до следующего тиража. Основной параметр — текущий пропуск числа и его исторические совпадения в строгой/мягкой матрице.
🔥 Рейтинг чисел сейчас
Тек. инт. — сколько тиражей пропущено после последнего появления. «Стр.» — сколько раз этот интервал закрывался между соседними появлениями. «Мяг.» — сколько раз он встречался среди всех пар.
🎯 Готовые K7
Готовая K7 ещё не имеет истории. Для наблюдения вперёд нажмите «СОХРАНИТЬ K7». Только после сохранения комбинация попадёт в архив, и отсчёт начнётся со следующего тиража.
📚 Архив сохранённых K7
Сюда попадают только K7, которые вы сами сохранили. Отсчёт начинается со следующего тиража после сохранения. При каждом обновлении архива карточка сама пересчитывает новые тиражи, выигрыши и повторные 7/7.
Архив хранится в IndexedDB браузера — не в localStorage. Старые сохранённые K7 при первом запуске автоматически переносятся в IndexedDB и удаляются из localStorage. В основное COMBO ничего не встроено.
🔎 История K7 — что реально совпало
Этот блок предназначен только для ручной проверки своей K7. Сохранённые комбинации открываются из «Архива сохранённых K7».
Результат появится здесь: 7/7, № тиража, дата, время, столб, интервал и дополнительные совпавшие числа.
